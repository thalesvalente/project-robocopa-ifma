# Minutas de descoberta e projeto

Preparação paralela às pendências locais/humanas da S00. Nenhuma minuta equivale a entrevista, aprovação institucional ou sprint homologada. O estado das tarefas macro permanece no backlog.

Entradas previstas: problema e público, jornadas, benchmark, ideação/priorização, hipóteses de validação, BMC, projeto, recursos/custos, trilha pedagógica, governança e pitch. Cada arquivo será identificado com sua tarefa e estado ao ser publicado.

O princípio central é permitir participação real pelo celular, sem exigir conhecimento prévio de desenvolvimento web/mobile. A primeira prova de valor será programar uma estratégia, executá-la no servidor e observar seu resultado; não apenas acompanhar um ranking.
